# Robustness of Neural Networks on Optimized Synthetic Images

Code for our degree project in technology, first cycle (15 hp). Written by authors Samuel Fors and Adam Landbü.

Neural networks are trained and tested in file "trainAndTest.ipynb".

The robustness of normal MNIST test images is calculated in file "experiment1.ipynb".

Images are generated (using single-model selective output maximization) and tested in file "experiment2.ipynb".

Multi-model images are generated and tested in file "experiment3.ipynb", along with some other experiments.

The neural networks are saved in the "networks" folder, every generated image is saved in the "generated_images" folder, and the computed results are saved the "results" folder. 

The report is also included as a .pdf file.
